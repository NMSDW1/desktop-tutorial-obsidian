# 五峰

[[五峰]] 是 [[太和仙宗]] 的正式组织结构。以下名称、方向与当前立场以母库《太和仙门设定更新》为准；更细的传承沿革仍可继续补充。

## 待补字段

- 金峰：峰主顾凌锋，道号肃锋真人；剑修、杀伐、战斗；总体支持副宗主沈明执。
- 木峰：峰主苏怀生，道号长春真人；丹道、灵植、医术、生命研究；总体支持宗主林清衡。
- 水峰：峰主谢观澜，道号玄澜真人；符箓、阵法、神魂、规律与遗迹理论；总体支持宗主林清衡。
- 火峰：峰主陆明铸，道号赤工真人；炼器、火系术法、技术发展；总体支持副宗主沈明执。
- 土峰：峰主韩镇岳，道号厚岳真人；体修、防御、宗门建设、灵脉维护；总体支持宗主林清衡。
- 与 [[三院]] 的关系：五峰负责专业传承与资源，三院负责典籍研究、遗迹研究和传道培养；三院原则上保持议题中立。
