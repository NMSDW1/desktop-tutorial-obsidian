# 五峰

[[五峰]] 与 [[三院]] 平级，是 [[太和仙门]] 的修炼与专业传承主体。

## 金峰
- 方向：剑修、杀伐、战斗。
- 峰主：顾承锋——化神一层。
- 执法长老：韩肃川——结丹五层。
- 普通长老：陆问剑——结丹四层。
- 普通长老：程守岳——结丹四层。
- 编制：1峰主 + 3长老。

## 木峰
- 方向：丹道、灵植、医术、生命相关修行。
- 峰主：苏青岚——结丹五层。
- 执法长老：宁守春——结丹四层。
- 普通长老：温若谷——结丹三层。
- 编制：1峰主 + 2长老。

## 水峰
- 方向：符箓、阵法、神魂、推演与规律研究。
- 峰主：江玄流——结丹五层。
- 执法长老：洛沉舟——结丹四层。
- 普通长老：沈观澜——结丹三层。
- 编制：1峰主 + 2长老。

## 火峰
- 方向：炼器、火法、创造、技术发展。
- 峰主：赤明远——化神一层。
- 执法长老：钟烈山——结丹五层。
- 普通长老：楚焚星——结丹四层。
- 普通长老：秦炉生——结丹四层。
- 编制：1峰主 + 3长老。

## 土峰
- 方向：体修、防御、宗门建设与灵脉维护。
- 峰主：石镇岳——结丹五层。
- 执法长老：岳重玄——结丹四层。
- 普通长老：方厚载——结丹三层。
- 编制：1峰主 + 2长老。

## 当前结构特征
- 金峰、火峰保留三长老编制，整体实力高于木、水、土三峰。
- 木、水、土三峰为两长老编制。
- 五峰制度上平级，但实力与资源能力并不完全相同。
- 人物性格、派系与彼此关系暂不在本页固化，留待后续统一设计。
