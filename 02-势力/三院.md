# 三院

[[三院]] 是 [[太和仙宗]] 的正式组织结构，原则上不固定站队，根据议题、证据与宗门长期价值判断。

## 待补字段

- 万法阁：阁主温知微，道号见微真人；负责典籍、残篇、万法联系与理论研究。
- 遗迹院：院主裴远川，道号寻古真人；负责上古遗迹、异常空间、古代文明及玄衡宗主失踪线索。
- 传道院：院主程守一，道号归一真人；负责新人培养、基础课程、共同理念与早期分流。
- 与 [[五峰]] 的关系：五峰承担专业传承与资源建设，三院承担研究、传道与跨峰协调。
