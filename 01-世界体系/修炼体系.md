# 修炼体系

## 人族正式大境界

**已知境界：引气 → 筑基 → 结丹 → 元婴 → 化神 → 合道**

**推测终境：登仙（尚无人证实）**

- 旧版“炼脉”已取消。
- 每个大境界分五重。
- 大境界决定能力层级，小境界决定完成度与上限。
- 筑基之后跨越大境界需要面对天劫或相应生命结构跃迁检验。

## 七境核心质变

### 引气
感气入体，建立最初可控循环。
五重：感气 → 纳气 → 行气 → 御气 → 周天。

### 筑基
把暂时灵气循环改造成身体可长期承载的稳定修行结构。
五重：定脉 → 拓脉 → 固府 → 灵体初成 → 基成。

### 结丹
将分散灵力压缩成稳定力量核心。
五重：凝核 → 固丹 → 养丹 → 丹化周身 → 丹极。

### 元婴
神魂、丹核与个人修行之道融合，形成第二生命中枢。
五重：婴成 → 婴固 → 婴游 → 神体相合 → 婴极化神。
元婴离体不是轻易复活机制，肉身毁灭后元婴会持续衰弱且极易被针对。

### 化神
从控制自身力量，进阶到稳定感应、牵引和干涉天地之气。
五重：神感天地 → 借天地之力 → 神御万法 → 域势初成 → 神与天地相应。

### 合道
自身修行之道稳定嵌入天地规律。
五重：道痕初成 → 道域成形 → 身道相合 → 借天地成法 → 一念近道。
合道足以改变三宗均势，是时代级战力。

### 登仙（推测终境）
登仙尚未被证实存在，目前没有任何被公认、被可靠记载的登仙者。飞升仙界、长生不死、破界而去、仙上有境等说法都只是不同学派的推测。合道五重是当前修仙界真正可以确认的最高层次。

## 一重至五重统一规则

- 一重：初入
- 二重：稳固
- 三重：成熟
- 四重：大成
- 五重：圆满并触碰下一境特征

同境相差一重已有明显差距，两重以上优势显著，三重以上通常很难靠正面硬碰弥补。功法、法器、阵法、环境、情报与体系克制仍可创造越级可能。

## 寿命与战斗尺度

| 境界 | 大致寿命 | 常见战斗尺度 |
|---|---:|---|
| 引气 | 80—120年 | 单人、院落、小规模冲突 |
| 筑基 | 150—220年 | 建筑、街巷、小队战 |
| 结丹 | 300—500年 | 城区、军阵、宗门分部 |
| 元婴 | 700—1000年 | 城池、大型战场 |
| 化神 | 1500—2500年 | 山域、宗门战争 |
| 合道 | 4000—8000年 | 山河、区域级天地影响 |
| 登仙 | 未知 | 未知（仅为推测终境） |

> 破坏范围 ≠ 单挑实力。战力最终由境界、体系、功法、法器、环境与情报共同决定。

## 七大体系成长路线

### 剑修
**引气练锋 → 筑基练御 → 结丹练势 → 元婴练意 → 化神练域 → 合道练道**

核心：把复杂世界压缩成一击。

### 法修
**引气学引 → 筑基学化 → 结丹学控 → 元婴学合 → 化神学境 → 合道学法**

核心：把复杂世界展开成万法。

### 体修
**引气炼血 → 筑基炼骨 → 结丹炼身 → 元婴炼命 → 化神炼势 → 合道炼体之道**

核心：把力量炼进自身。

### 丹修
**引气识性 → 筑基炼药 → 结丹炼机 → 元婴炼魂 → 化神炼命 → 合道炼生**

核心：研究生命与转化。

### 器修
**引气识材 → 筑基成器 → 结丹炼灵 → 元婴御群 → 化神造域 → 合道铸则**

核心：把能力固化进器物。

### 符修
**引气识纹 → 筑基成符 → 结丹叠式 → 元婴赋念 → 化神布域 → 合道刻则**

核心：把术法写成可执行结构。

### 阵修
**引气识位 → 筑基成阵 → 结丹联势 → 元婴御域 → 化神借天 → 合道定则**

核心：把环境组织成力量系统。

## 七路与多世界统一理论

七大体系不是七种不同能源，而是修仙文明对同一“气”的七种主要使用方式。最终都可重新归入主角后期总结的：

**本、术、势、器、域**

这为后期跨世界统一力量理论提供基础。

## 宗门修为层级原则

- 弟子主力：引气、筑基。
- 核心弟子与执事：筑基至结丹。
- 普通长老：以结丹境为主。
- 少数核心长老：可达到元婴一重。
- 峰主、院主、堂主：原则上进入元婴境。
- 三大仙门现任宗主：统一为化神五重。
- 太和副宗主 [[副宗主|沈明执]]：化神四重。
- 合道：足以打破当前三宗均势的时代级战力。

## 当前三宗顶层基准

- 太和仙门宗主 [[林清衡]]：化神五重。
- 天宸仙门宗主萧镇玄：化神五重。
- 玄霄仙门宗主楚玄真：化神五重。
- [[副宗主|沈明执]]：化神四重。

## 突破机制与天劫

- **引气→筑基：立基**。不设正式天劫，核心是重塑经脉、稳定丹田、建立长期循环。
- **筑基→结丹：凝丹**。主要面对灵压劫。
- **结丹→元婴：破丹化婴**。主要面对神魂劫，“心魔”本质是生命重构时的意识失稳。
- **元婴→化神：开神门**。主要面对天地劫。
- **化神→合道：立道**。主要面对问道劫，每个人因自身之道不同而异。
- **合道五重之后**：是否存在真正可行的登仙突破，无可靠答案。

失败后果分为：轻败、重败、道伤、陨落。

## 功法、种族与外物修正

- 功法主要影响效率、稳定、适配与突破失控概率，不直接固定增加寿命。
- 人族：寿命基础短、适应强、体系完整。
- 妖族：同境寿命通常高于人族，但更依赖血脉、本体与环境。
- 魔族：不套人族寿命表，主要风险是吞噬反噬和结构崩溃。
- 丹药与外物可以辅助突破，但长期依赖可能导致丹毒、耐药、根基不稳与结构失衡。

> **丹可助道，不可替道。**

## 仍待细化

- 各境日常修炼方式与资源消耗。
- 灵石、灵脉、丹药、功法品阶等资源体系。
- 神识、灵力、肉身三类基础参数的战斗表现。
- 七大体系更具体的克制与协同。
- 法器、丹药、符箓、阵法的品阶与境界对应。
- 妖族完整境界体系。
- 魔族各境界与人族六个已知境界的精准对应。
- 合道强者的历史数量、现存情况与失踪记录。
- “登仙”古籍传说的流派、证据与矛盾。
- 主角未来如何发现现有修炼体系解释不了跨世界力量。
