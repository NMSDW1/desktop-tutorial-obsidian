# 小说知识库 / Obsidian Vault

这是从 `desktop-tutorial` 独立出来的 Obsidian 知识库。它专门用于结构化整理小说世界观、人物、剧情、伏笔与灵感。

## 入口

- [知识库首页](00-总纲/知识库首页.md)
- [世界观总纲](00-总纲/世界观总纲.md)
- [迁移说明](迁移说明.md)
- [待确认事项](00-总纲/待确认事项.md)

## 目录

- `00-总纲`：首页、总纲与待确认事项
- `01-世界体系`：修炼体系与核心理念
- `02-势力`：太和仙宗、五峰、三院与相关机构
- `03-人物`：人物索引与人物卡
- `04-剧情`：剧情索引、伏笔与事件
- `05-灵感库`：尚未定稿的创作灵感
- `06-网文研究`：平台与写作研究
- `07-临时设定`：带有 `status: 临时` 的草案

在 Obsidian 中直接选择本仓库目录作为 Vault 即可，无需安装额外插件。GitHub 仍可直接浏览所有标准 Markdown 文件。

旧知识库仍保留在 [`desktop-tutorial`](https://github.com/NMSDW1/desktop-tutorial)，两边会同步记录已确认的新小说内容。
