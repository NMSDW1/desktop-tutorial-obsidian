# 网文与文学人物研究库

> 与小说世界观/剧情母版完全分离。研究成果仅作为后续剧情需要时的方法参考库。

## 使用规则
- 每日08:00、18:00各研究20本网文+5部经典文学作品。
- 约40%网文样本为修仙/仙侠/玄幻修炼体系。
- 18:00轮尽量避开当天08:00作品，并避免近期重复。
- 数据注明日期与公开来源；无法核实则不当事实。
- 只迁移人物塑造、冲突、节奏、伏笔、反转等方法/机制/结构，不照搬人物、情节、设定或表达。

## 长期研究维度
人物欲望、价值观、底线、恐惧、缺点、习惯、语言、行为选择、微动作、心理、人物关系、压力反应、人物弧光、关系映照、时代与制度塑造，以及商业网文与经典文学人物写法的融合。
