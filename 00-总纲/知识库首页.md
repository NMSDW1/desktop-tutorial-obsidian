# 小说知识库

这是一个兼容 Obsidian 与 GitHub 的 Markdown Vault。笔记按主题拆分，通过 `[[双向链接]]` 连接世界观、人物、剧情和研究资料。

## 主要模块

- [[世界观总纲]]：当前世界观的总入口与范围说明
- [[修炼体系]]：境界、力量与修炼规则
- [[太和仙宗]]：宗门总览
- [[五峰]]：宗门五峰的结构入口
- [[三院]]：宗门三院的结构入口
- [[人物索引]]：人物笔记入口
- [[剧情索引]]：主线、伏笔与重大事件
- [[灵感库索引]]：尚未完全定稿的创作灵感
- [[网文研究索引]]：平台与写作方法研究
- [[临时设定索引]]：带有 `status: 临时` 的内容

## 快速约定

1. 新想法先放入 `07-临时设定/`，并添加 `status: 临时`。
2. 已确认设定放入对应模块，并保留来源或确认日期。
3. 概念首次出现时尽量使用 `[[页面名]]`；链接目标不存在时，Obsidian 会显示为待创建页面。
4. 不删除旧目录内容；旧目录仅作为兼容入口，迁移状态见 [[迁移说明]]。
